# 엔지니어링 노트 디자인

- 방향: 차분한 매거진. 큰 제목, 넓은 여백, 정돈된 최신 글 목록.
- 기반: Retypeset. 아이보리 바탕과 따뜻한 먹색, 제한적인 테라코타 강조.
- 글: 한글 시스템 sans, 충분한 행간, 본문 폭 제한. 코드와 표는 자체 가로 스크롤.
- 화면: 375 / 768 / 1440px. 키보드 focus, 44px 조작 영역, reduced-motion, light/dark 확인.
- 정보: 글 · 주제 · 검색 · 소개. 원문 49개와 기존 URL은 디자인 변경과 별도로 대조한다.

- 첫 화면: 대표 글과 자체 SVG 일러스트, 함께 읽기 한 편, 나머지 최신 글 두 칸 목록. 모바일은 한 칸으로 전환한다.
- 시선 순서: 대표 제목 → 요약 → 읽기 링크 → 글 목록. 반복 카드보다 크기와 여백 차이로 위계를 만든다.
- 참고: [Increment](https://increment.com/)의 대표 글 구성, [Linear Now](https://linear.app/now)의 주제별 탐색. 구현은 기존 Astro/CSS를 사용한다.
